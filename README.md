# RoleReady AI: AI Job Description Analyzer 🚀

**RoleReady AI** is a smart web application designed to help students, fresh graduates, and job seekers prepare for jobs more effectively by analyzing job descriptions using artificial intelligence.

---

## 🌟 Project Overview
The platform allows users to paste a job description from any job posting, and the system automatically extracts important skills, technologies, frameworks, and keywords related to the job role. Based on the extracted information, the platform generates interview questions, learning recommendations, important technical topics, and project suggestions.

## 🎯 Main Goals
- Help users understand job descriptions easily.
- Extract important technical skills automatically.
- Generate interview preparation content (MCQs & Scenarios).
- Recommend structured learning roadmaps.
- Provide AI-powered career guidance for freshers.

## 🛠️ Core Features
1. **Job Description Analyzer:** Instant extraction of skills, tools, and keywords from any JD.
2. **AI Interview Question Generator:** Generates 20 Technical MCQs and Behavioral scenarios tailored to the role.
3. **Career Path Roadmap:** Creates a structured learning journey (Step 1, Step 2, etc.).
4. **Interactive Workspace:** A dual-pane editor for personal planning and AI-guided visualization.
5. **Live Visualizer:** Converts typed goals into animated roadmap cards instantly.

## 💻 Tech Stack
- **Frontend:** HTML5, CSS3 (Vanilla Premium Design), JavaScript (ES6+).
- **AI Integration:** Google Gemini API (1.5 Flash/Pro).
- **Styling:** Custom CSS with Glassmorphism and Animated Orbs.
- **Deployment:** Vercel.
